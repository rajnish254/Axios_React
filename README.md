Axios :- Axios is a JavaScript library used to make HTTP requests from your React app

GET (fetch data)

POST (send data)

PUT / PATCH (update data)

DELETE (remove data)

In React, Axios is mostly used to: fetch data from APIs and show it in components.

Advantages of Axios over fetch:

1. Automatic JSON handling

2. Cleaner syntax (Promise-based)

3. Better error handling

4. Request & response interceptors
